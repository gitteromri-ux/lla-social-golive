## File naming

`<POST-ID>_<PLACEMENT>_<WIDTHxHEIGHT>.<ext>`

- `IG-REEL-STORY_1080x1920` — Instagram Reel, Instagram Story, Facebook Reel, Facebook Story
- `IG-FEED_1080x1350` — Instagram feed (4:5), also correct for the Facebook feed
- `SQUARE_1080x1080` — 1:1, use only if a square is requested
- `FB-FEED_1280x720` / `FB-FEED_1920x1080` — Facebook feed video, native 16:9, highest quality
- `IG-STORY_1080x1920` — image stories
- `FB-LINK_1200x630` — Facebook link/share image (1.91:1)

## Technical specification of the delivered files

- Video: H.264 High, yuv420p, AAC audio track present on every file, `faststart` enabled, minimum 8 seconds so Reels accept them, seamless loops.
- Vertical and square videos keep the **entire original frame**, centred on a blurred version of the same footage. Nothing is cropped out and nothing is upscaled beyond the source, so no detail is lost.
- Images: progressive JPEG, quality 92, every file under Instagram's 8 MB limit, exact pixel dimensions in the file name.
- All motion and photography comes from the live website and from cleared instructor photography. No newly designed static banners.
